# Case Template Timeline Prototype Imagegen Review

Built-in image generation was used for five UI mockup references before coding. The generated concepts were reviewed for timeline fit, hierarchy, and whether they respected the existing Intercept three-column case detail structure.

## Option 01: Inline PICERL Stage Bands

Prompt focus: PICERL stages as compact bands above existing timeline cards, with overlap indicators and progress chips.

Refinement applied: Kept the stage layer shallow and timeline-native. The prototype uses stage cells above normal cards instead of a separate playbook panel.

## Option 02: Template Command Center Dock

Prompt focus: RightDock as the template governance surface, with source-of-truth, required steps, and generated task preview controls.

Refinement applied: The dock owns attach/apply decisions while the timeline shows only selected-item context and generated-item previews.

## Option 03: Template-Generated Task Cards

Prompt focus: Template steps become first-class timeline task cards with owner, status, due date, dependencies, and PICERL phase chips.

Refinement applied: The prototype makes template work look like normal case work, not an embedded checklist.

## Option 04: Swimlane Timeline Overlay

Prompt focus: Parallel PICERL lanes showing overlapping stages and cross-lane dependencies.

Refinement applied: The first render felt too wide for the case detail center column, so the coded version uses a tighter grid that still communicates overlap inside the existing shell.

## Option 05: Template Health Layer

Prompt focus: A lightweight health/status layer for escalation-to-case, template gaps, undo, and ghost suggested tasks.

Refinement applied: The prototype keeps the health layer compact and leaves timeline items as the dominant surface.
